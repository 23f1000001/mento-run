# mento-run

As a graduate, i want to build a profile and set my expertise where I am knowledgeable

As a student, I want recommendations and suggestions on who is matching for the guidance I need

As a student i want to be able to set my profile, set preferences, be able to search and add them.

As program administrator I want to be able to manage and see metrics of the platform

as a mentor I want to be able to accept/reject requests.
